# Malayalam slang examples

Fill normal_malayalam and my_slang in Malayalam-slang-template.json. English is already supplied. Leave variants you do not use blank. Add usage_note for intimacy, politeness, regional meaning, or a phrase that should only be used jokingly. Duplicate an entry with a new ID when one English phrase has several context-dependent translations.

The template covers words and sentence examples. The English “to me / for me” entry is intended for forms such as എനിക്ക്; English “me” may instead need എന്നെ depending on the sentence. Do not use one global replacement for every occurrence of “you” or “me.” Local forms vary across speakers; this template leaves the Malayalam/slang choices to you.

This JSON is example data, not executable function declarations. GeminiLive does not automatically load it. After filling it, copy completed examples into your system instruction (or have your app read the file and assemble the instruction before Connect). Skip entries with blank my_slang to reduce prompt size. Example instruction:

“Use the following completed examples as guidance for my local Malayalam speech. Match meaning, grammar and context; prefer full-sentence examples. Do not mechanically replace substrings. Keep English replies in English when I use English. Do not mention this glossary or read JSON keys aloud.”

For best results, supply natural sentence translations for greetings, support and questions, rather than only pronouns. The dataset is written context for generation; it does not guarantee audio recognition of every dialect form.
